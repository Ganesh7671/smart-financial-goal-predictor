# Financial Recommender App

This application analyzes your expenses and provides personal financial advice using Machine Learning models.

## Requirements

The project uses the following Python libraries:
- streamlit
- pandas
- numpy
- joblib
- tensorflow
- xgboost
- matplotlib
- seaborn
- scikit-learn

## Setup and Installation

1.  **Install Dependencies:**
    Open your terminal or command prompt in this directory and run:
    ```bash
    pip install -r requirements.txt
    ```

2.  **Run the Application:**
    Execute the following command to start the Streamlit app:
    ```bash
    streamlit run app.py
    ```

## Usage

- Enter your financial details (Income, Age, Rent, etc.) in the input form.
- Click **Submit**.
- Explore the **Visualizations**, **Predictions**, and **Recommendations** tabs.
